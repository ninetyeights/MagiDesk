# 按规则整理文件

从主窗口的“文件整理”进入，也可以打开盒子菜单，选择“按规则整理文件…”，带入当前盒子或分页显示的项目。

## 使用步骤

1. 选择文件夹或多个文件。文件夹仅扫描当前层；子文件夹、系统图标和重解析点不参与整理。一次最多 10000 项。
2. 添加规则，设置目标目录、复制或移动、重名时跳过或自动改名。规则从上到下，只使用第一条匹配的规则。
3. 点击“预览整理结果”，核对来源、目标和跳过原因。预览不会创建目录或改动文件。
4. 点击“执行预览中的操作”。执行前会再次检查文件状态和目标冲突；部分失败不影响其他项目。

同一条规则的条件需要全部满足。扩展名可填 `jpg,png,webp`，留空表示不限；文件名支持 `*` 和 `?`，例如 `截图*`；“至少几天未修改”填 `30` 表示最后修改已超过 30 天，填 `0` 表示不限。示例：扩展名 `pdf`、文件名 `发票*`、天数 `0`，移动到指定的发票目录。

“保存规则”可单独保存；预览时也会保存规则。更改规则或整理范围后需要重新预览。没有自动监控或定时整理。

## 执行记录与撤销

只保留最近一批执行记录，启动新批次会替换旧记录。通过“查看上次结果”可在重启后查看，并撤销其中已完成的项目。

撤销移动会将文件移回原位；撤销复制会删除本次生成的副本。撤销前会核对目标的文件身份、修改时间、长度和内容。文件已变化、原位置被占用、原目录不存在或文件系统无法提供文件身份时，会保留文件并显示原因。执行时创建的空目录不会在撤销时删除。

“停止后续操作”不会强行中断正在进行的单个文件复制或移动。异常退出留下的“中断待核对”项目不会自动撤销，请根据来源和目标检查实际文件。记录保存在 `%APPDATA%\MagiDesk\organizer-history.jsonl`。

## 手工验收

用临时文件验证盒子入口、规则编辑与横向滚动、复制/移动、执行后刷新和重启后撤销。跨磁盘、网络共享及真实权限不足场景仍需手工验收；自动测试只操作独立的测试临时目录。
