MagiDesk 首个公开测试版本，优先支持 Windows 11 x64。

包含窗口拖动与吸附、窗口分区与多窗口联动缩放、快速网格、桌面盒子、应用 Dock、浏览器微标和启动参数管理。首次启动默认只开启窗口拖动，其他功能按需开启。

下载文件说明：
- `win-x64-Setup-*.exe`：常规 Intel / AMD Windows 电脑安装版。
- `win-arm64-Setup-*.exe`：Windows ARM64 安装版，尚需对应设备实机验证。
- `.zip`：自包含便携版，完整解压后运行，无需另装 .NET。
- `.sha256`：人工核验下载完整性；`update-manifest.json` 与 `.sig` 用于应用内更新签名验证。

安装版按当前用户安装，无需管理员权限；升级、卸载保留用户配置和真实桌面文件。升级前建议备份 `%APPDATA%\MagiDesk`。安装程序尚无 Windows Authenticode 签名。

已知限制：跨 DPI 恢复资源管理器可能存在短暂空白；Windows 10、ARM64、屏幕热插拔及远程桌面恢复尚未全面实机验收。首个测试版不能代表全部环境验证完成。

自动检查更新默认关闭，可在“关于”页面手动检查。此版本首次引入签名更新，完整旧版到新版在线升级需后续版本实机验收。
