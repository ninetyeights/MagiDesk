MagiDesk v0.1.0-beta.3，关于页面的小幅调整。

### 本次调整
- 移除关于页面中过时的“已实现的工具”卡片和“更多工具陆续加入”提示。
- 保留版本、技术栈和应用更新区域。其余功能与 beta.2 一致。

### 下载与升级
- `win-x64-Setup-*.exe`：Intel / AMD Windows 安装版。
- `win-arm64-Setup-*.exe`：Windows ARM64 安装版，仍需对应设备实测。
- `.zip`：自包含便携版，完整解压后运行，无需另装 .NET。
- `.sha256` 用于完整性核验；`update-manifest.json` 和 `.sig` 用于应用内更新签名验证。

安装版按当前用户安装，升级与卸载保留用户配置和真实文件。升级前建议备份 `%APPDATA%\MagiDesk`。安装程序尚无 Windows Authenticode 签名。自动检查更新默认关闭，可在“关于”中手动检查测试版更新。

### 已知限制
跨 DPI 恢复资源管理器可能短暂空白；Windows 10、ARM64、屏幕热插拔、远程桌面恢复及在线升级仍需实测。其他启动器与主程序分离的应用尚未全部适配。
