MagiDesk 第二个公开测试版本，包含首版后的修复与项目库增强。

### 新增与调整
- **模拟器实例识别**：在项目库点击“识别模拟器实例”，批量导入 BlueStacks 5 / MSI App Player 5 实例；保留名称，通过 `--instance` 分别启动和识别，已有实例自动跳过。
- **Dock 内容布局锁定**：统一保护添加、删除、移动、重命名和图标编辑，提供明确的“解锁并编辑”入口。正常启动应用、浏览和切换集合不受影响。
- **浏览器参数精简**：移除命令预览，保留输入框；新增通话音频预设 `--disable-features=ChromeWideEchoCancellation,WebRtcAllowInputVolumeAdjustment`，应用时合并已有参数，需保存并彻底退出浏览器后重启。关闭回声消除可能增加外放通话的回声。
- **桌面盒子**：统一桌面显示改为固定行为，移除实验选项；仅在开启桌面盒子时生效，首次启动仍默认关闭盒子功能。

### 修复
- Docker Desktop 的启动器与实际窗口进程路径不同，导致固定项未显示运行状态、在“正在运行”中重复出现的问题。
- 从运行中列表固定 Docker Desktop 时重复创建项目的问题。
- 主窗口拖动后标题栏按钮悬停高亮残留的问题。
- 统一桌面初始化失败时，恢复系统桌面图标并停用盒子功能。

### 下载与升级
- `win-x64-Setup-*.exe`：Intel / AMD Windows 安装版。
- `win-arm64-Setup-*.exe`：Windows ARM64 安装版，仍需对应设备实测。
- `.zip`：自包含便携版，完整解压后运行，无需另装 .NET。
- `.sha256` 用于完整性核验；`update-manifest.json` 和 `.sig` 用于应用内更新签名验证。

安装版按当前用户安装，升级与卸载保留用户配置和真实文件。升级前建议备份 `%APPDATA%\MagiDesk`。安装程序尚无 Windows Authenticode 签名。自动检查更新默认关闭，可在“关于”中手动检查测试版更新。

### 验证与已知限制
构建与 347 项无界面测试通过；未将自动测试等同于实机验收。跨 DPI 恢复资源管理器可能短暂空白；Windows 10、ARM64、屏幕热插拔、远程桌面恢复及 beta.1 → beta.2 在线升级仍需实测。其他启动器与主程序分离的应用尚未全部适配。
