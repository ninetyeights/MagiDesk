MagiDesk v0.1.0-beta.4，修复固定应用启动和模拟器实例识别，精简配置保存提示。

### 修复与调整
- **固定应用启动**：修复从运行中固定商店打包应用后，关闭再点击无法启动的问题。按包清单精确解析 Windows 应用入口，现有固定项无需删除重加。
- **模拟器按实例显示**：修复带引号的 `"--instance"` 参数无法识别的问题。未固定实例独立显示、独立预览，可固定到栏目并复用已有实例项目。
- **未识别实例兜底**：暂时无法识别身份时按窗口分别显示并标注，不再合并或固定为通用模拟器入口。
- **保存状态提示**：正常时只显示自动保存说明；失败时显示警告、详情和重试按钮，成功后自动收起。修复重新进入设置页后状态监听失效的问题。
- 补充应用启动失败的错误码日志。配置备份和恢复界面后续再添加。

### 下载与升级
- `win-x64-Setup-*.exe`：Intel / AMD Windows 安装版。
- `win-arm64-Setup-*.exe`：Windows ARM64 安装版，仍需对应设备实测。
- `.zip`：自包含便携版，完整解压后运行，无需另装 .NET。
- `.sha256` 用于完整性核验；`update-manifest.json` 和 `.sig` 用于应用内更新签名验证。

安装版按当前用户安装，升级与卸载保留用户配置和真实文件。升级前建议备份 `%APPDATA%\MagiDesk`。安装程序尚无 Windows Authenticode 签名。自动检查更新默认关闭，可在“关于”中手动检查测试版更新。

### 已知限制
跨 DPI 恢复资源管理器可能短暂空白；Windows 10、ARM64、屏幕热插拔、远程桌面恢复及在线升级仍需实测。其他启动器与主程序分离的应用尚未全部适配；打包应用升级后旧 EXE 路径失效的自动迁移尚未实现。
