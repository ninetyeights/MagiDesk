# 统一桌面显示实验

设置入口：桌面盒子 → 统一桌面显示（实验）。默认关闭，需同时启用桌面盒子。

## 当前范围

- 未归类文件：在主屏工作区的透明窗口中显示，复用盒子的选择、重命名、剪贴板和文件右键操作。
- 普通盒子：按已有成员关系分组；拖入、拖回桌面只改变归属，不搬动桌面文件。
- 映射盒子：继续显示映射目录，不参与桌面成员排除。
- 桌面文件夹双击：打开 Explorer；普通盒子的导航不变。
- 用户桌面和公共桌面均有文件变化监听。
- 临时隐藏 Explorer 图标窗口，不切换其持久化“显示桌面图标”设置。
- 恢复进程监控主程序，正常退出、关闭实验或主程序崩溃时恢复本次隐藏的窗口；原本隐藏的图标不强制显示。
- 原“桌面”盒子的几何和外观配置保留，退出实验后继续使用。

## 限制

这是显示架构原型，不是完整桌面替代：主屏网格、无自由摆放/原位置导入、多屏分配。回收站、此电脑、网络等 namespace 图标从 Explorer 当前桌面视图读取，跟随系统启用状态；支持系统名称、图标、双击打开及原生右键。暂不支持拖动这些图标、向其拖入文件、内联重命名或文件剪贴板操作；混合选择含系统图标时，不执行部分复制/剪切/删除。修改系统图标设置后可右键刷新。桌面图标从上到下、再从左到右排列，超出工作区的项目可滚动访问。空白右键从 Explorer 桌面视图取得原生菜单，以经典 Shell 菜单方式展示；普通盒子继续使用目录菜单。已接入原生图标大小、名称/大小/类型/修改时间排序及升降序、显示桌面图标状态读取，菜单命令后立即同步并有限重读以覆盖异步命令。隐藏图标仅隐藏透明桌面的未归类图标，保留空白右键入口，不隐藏盒子。关闭自动排列、关闭对齐网格后的自由摆放尚未实现；类型排序仍沿用本应用的扩展名排序，并非 Explorer 类型显示名称排序。Explorer 重启后可能恢复系统图标，应关闭再开启实验。整个进程树被强制结束时恢复进程也会退出，可在系统桌面切换“显示桌面图标”或重启 Explorer 恢复。

## 手工验证（待用户运行）

1. 启用实验：普通文件各显示一次，Explorer Desktop 文件夹中的文件数量、路径不变。
2. 从透明桌面拖入普通盒子，再拖回透明桌面：仅归属改变；关闭盒子后成员回到桌面。
3. 映射盒子显示同一路径时，未归类桌面文件不被错误排除。
4. 反复点击重叠盒子、透明区域；盒子仍在透明区域上方，其他应用仍覆盖它们。
5. 框选、Ctrl+A、重命名、文件右键、双击文件夹、桌面外部新建/删除/重命名。
6. 开关反复切换、托盘退出、仅结束主程序进程：系统图标恢复，原“桌面”盒子位置不变。
7. 原系统图标已隐藏时启用并退出：仍维持隐藏。
8. 普通盒子空白右键 → 新建文件夹/文本文档：新项目归入当前盒子；桌面新建仍在桌面，映射盒子新建仍在映射目录。取消新建菜单不改变成员；其他程序同时创建桌面文件不应被收进盒子。
9. 新建文件出现时直接进入重命名，文件仅选中文件名主体，文件夹选中全名；Enter、点击其他文件/空白处或切换应用确认名称，Esc 取消编辑并保留新建项。验证列表、网格、仅图标、长列表末尾及映射目录，文件监听刷新不应立即关闭编辑框。
10. 新盒子默认无边框；已保存的边框选择仍沿用原配置。
11. 桌面按列排列：同列从上到下，满列后移向右侧；验证方向键、框选、Tab 连续重命名、窗口高度变化和超出一屏的文件。普通盒子仍按行排列。
12. 桌面空白右键应出现系统桌面菜单，检查显示设置、个性化、新建、粘贴和刷新。检查 `SHELL-MENU stage=desktop-background-menu` 的结果；经典菜单外观与 Windows 11 首层菜单不同。
13. 切换大/中/小图标、各排序字段及升降序；框选、方向键和 Tab 重命名位置应跟随新尺寸。取消“显示桌面图标”后，未归类图标不可见/不可选，但仍可空白右键恢复显示。隐藏后退出应保持用户的隐藏选择。重启实验后从 Explorer 重新读取设置。

新建归属使用原生 `INewMenuClient` 回调的确切文件路径，不通过文件监听的时间窗口猜测。日志 `SHELL-MENU stage=new-item-site` 表示接口接入结果，`FENCE-NEW` 表示收到回调并处理归属。第三方新建扩展是否遵守此回调需实际验证。

新增 HeadlessTests 用例覆盖归类排除、大小写路径、映射盒子不抢占、删除分组后的返回和开关持久化。按用户要求未编译或运行，以上行为尚未通过实际桌面验证。

状态日志：`%TEMP%\magidesk.log`，关键词 `DESKTOP-SURFACE`。
