# 统一桌面显示实验

设置入口：桌面盒子 → 统一桌面显示（实验）。默认关闭，需同时启用桌面盒子。

## 当前范围

- 未归类文件：按屏幕归属在各显示器工作区的透明窗口中显示，复用盒子的选择、重命名、剪贴板和文件右键操作。
- 普通盒子：按已有成员关系分组；拖入、拖回桌面只改变归属，不搬动桌面文件。
- 映射盒子：继续显示映射目录，不参与桌面成员排除。
- 桌面文件夹双击：打开 Explorer；普通盒子的导航不变。
- 用户桌面和公共桌面均有文件变化监听。
- 临时隐藏 Explorer 图标窗口，不切换其持久化“显示桌面图标”设置。
- 恢复进程监控主程序，正常退出、关闭实验或主程序崩溃时恢复本次隐藏的窗口；原本隐藏的图标不强制显示。
- 原“桌面”盒子的几何和外观配置保留，退出实验后继续使用。

## 限制

这是显示架构原型，不是完整桌面替代：已实现多屏分配、跨屏拖动、网格/自由摆放、位置记忆及首次原生位置导入；真实多屏验收仍待完成。回收站、此电脑、网络等 namespace 图标从 Explorer 当前桌面视图读取，跟随系统启用状态；支持系统名称、图标、双击打开及原生右键。这些图标可在自绘桌面内自由移动，回收站已支持拖入文件删除，其他系统图标暂不接受文件拖入；暂不支持跨盒子拖放、内联重命名或文件剪贴板操作；混合选择含系统图标时，不执行部分复制/剪切/删除。系统图标设置通过 Shell 通知与低频状态核对自动同步，也可手动刷新。桌面图标从上到下、再从左到右排列，超出工作区的项目可滚动访问。空白右键从 Explorer 桌面视图取得原生菜单，以经典 Shell 菜单方式展示；普通盒子继续使用目录菜单。已接入原生图标大小、名称/大小/类型/修改时间排序及升降序、显示桌面图标状态读取，菜单命令后立即同步并有限重读以覆盖异步命令。隐藏图标仅隐藏透明桌面的未归类图标，保留空白右键入口，不隐藏盒子。关闭自动排列、关闭对齐网格后的自由摆放已实现（详见下方）；统一桌面类型排序已使用 Shell 类型显示名称，普通盒子保持原有扩展名排序。Explorer 重启后恢复进程会重新接管桌面图标窗口，并通知主进程刷新内容、设置和层级；2026-09-19 已完成状态逻辑测试，真实重启验收待完成。整个进程树被强制结束时恢复进程也会退出，可在系统桌面切换“显示桌面图标”或重启 Explorer 恢复。

## 手工验证（待用户运行）

1. 启用实验：普通文件各显示一次，Explorer Desktop 文件夹中的文件数量、路径不变。
2. 从透明桌面拖入普通盒子，再拖回透明桌面：仅归属改变；关闭盒子后成员回到桌面。
3. 映射盒子显示同一路径时，未归类桌面文件不被错误排除。
4. 反复点击重叠盒子、透明区域；盒子仍在透明区域上方，其他应用仍覆盖它们。
5. 框选、Ctrl+A、重命名、文件右键、双击文件夹、桌面外部新建/删除/重命名。
6. 开关反复切换、托盘退出、仅结束主程序进程：系统图标恢复，原“桌面”盒子位置不变。
7. 原系统图标已隐藏时启用并退出：仍维持隐藏。
8. 普通盒子空白右键 → 新建文件夹/文本文档：新项目归入当前盒子；桌面新建仍在桌面，映射盒子新建仍在映射目录。取消新建菜单不改变成员；其他程序同时创建桌面文件不应被收进盒子。
9. 新建文件出现时直接进入重命名，文件仅选中文件名主体，文件夹选中全名；Enter、点击其他文件/空白处或切换应用确认名称，Esc 取消编辑并保留新建项。验证列表、网格、仅图标、长列表末尾及映射目录，文件监听刷新不应立即关闭编辑框。
10. 新盒子默认无边框；已保存的边框选择仍沿用原配置。
11. 桌面按列排列：同列从上到下，满列后移向右侧；验证方向键、框选、Tab 连续重命名、窗口高度变化和超出一屏的文件。普通盒子仍按行排列。
12. 桌面空白右键应出现系统桌面菜单，检查显示设置、个性化、新建、粘贴和刷新。检查 `SHELL-MENU stage=desktop-background-menu` 的结果；经典菜单外观与 Windows 11 首层菜单不同。
13. 切换大/中/小图标、各排序字段及升降序；框选、方向键和 Tab 重命名位置应跟随新尺寸。取消“显示桌面图标”后，未归类图标不可见/不可选，但仍可空白右键恢复显示。隐藏后退出应保持用户的隐藏选择。重启实验后从 Explorer 重新读取设置。

新建归属使用原生 `INewMenuClient` 回调的确切文件路径，不通过文件监听的时间窗口猜测。日志 `SHELL-MENU stage=new-item-site` 表示接口接入结果，`FENCE-NEW` 表示收到回调并处理归属。第三方新建扩展是否遵守此回调需实际验证。

新增 HeadlessTests 用例覆盖归类排除、大小写路径、映射盒子不抢占、删除分组后的返回和开关持久化。按用户要求未编译或运行，以上行为尚未通过实际桌面验证。

状态日志：`%TEMP%\magidesk.log`，关键词 `DESKTOP-SURFACE`。

## 2026-09-19：归属与 Explorer 恢复

- 用户和公共桌面的直接子项改名会在 UI 线程按事件顺序更新成员路径、映射根目录与导航历史，并使旧枚举结果失效。普通盒子模式也启用监听。目录改名会同步已保存的后代路径。
- 正常改名优先采用明确的重命名事件；后续补齐了身份校验与异常恢复，范围及限制见下方。
- 恢复进程沿用已有 200ms 窗口发现循环，识别 HWND/PID 变化及窗口消失后重建；每个新窗口单独记录恢复状态。主进程每秒只消费一个进程间通知，收到通知后最多尝试 5 次同步 Shell 设置，不持续枚举文件或调用 COM。
- 新增 17 项回归，含真实临时文件/文件夹监听、分组排除和 JSON 持久化。临时目录 Debug 构建通过，58 项无窗口测试连续三轮全部通过。未启动 MagiDesk、未重启 Explorer、未改变用户桌面。
- 待手工验证：从 Explorer 对盒子中的文件及文件夹连续改名；重启 Explorer 后确认没有重复图标、盒子仍在桌面层；分别在原图标显示/隐藏状态下启停功能，确认退出恢复；快速禁用再启用，确认旧监听事件不影响新会话。
- 日志关键词：`DESKTOP-SURFACE external rename applied`、`guard rebound`、`recovered Explorer view`。
## 2026-09-19：归属异常恢复补齐

普通盒子新增持久化 `MemberReferences`，与用于显示的 `Members` 分离。后台读取卷标识、128 位文件 ID 及创建时间；不读取文件内容、不跟随重解析点，不持有文件句柄。用户/公共桌面原始条目均参与核对，避免隐藏文件和同名条目导致错误判断。创建时间用于减少删除后 ID 被复用的误认风险，不承诺文件系统跨时间的绝对身份保证。

- 文件移走或删除后，从当前成员中移除，但保留缺失身份记录；原文件以相同身份移回桌面时恢复到原盒子。缺失记录最长 30 天，每盒最多保留最新 256 项，后续校验时清理。
- 同路径被另一个文件占用时，新文件留在未归类桌面；不会按名称继承旧成员。通过替换文件完成的原子保存也可能改变身份，此时需重新归类。
- 监听溢出后重新扫描；没有报错的事件丢失由每 30 秒一次后台元数据核对兜底。内容不变时不重新取 Shell 名称、不重绘、不保存配置；旧会话和旧版本的异步结果会丢弃。
- 显式拖放记录待确认归属，使用下一次新快照绑定身份；即使刚移回文件且快照还没更新，也不会被旧盒子的缺失记录抢回。拖回未归类桌面会清除原有归属。
- 恢复改名时同步相关目录导航与映射路径；同路径替换或漏掉改名也会失效相关缩略图缓存。
- 身份读取失败、扫描不完整或存在多个硬链接候选时不猜测。跨卷移动、复制产生的新身份不自动接续；旧版配置首次建立身份前的改名无法追溯。文件只在桌面范围核对，不扫描其他目录或整盘；单独映射盒子根目录的身份跟踪不在本轮范围内。

测试新增 `DesktopMembershipTests` 28 项，包括真实临时文件/文件夹移动、删除重建、没有监听回调的改名恢复、重启持久化、手动归属优先级、硬链接歧义、不可访问目录、身份读取失败、记录过期和数量上限。Debug 构建成功，完整 86 项无窗口测试连续三轮通过；没有启动应用、改动用户桌面或重启 Explorer。

建议实机验收：从 Explorer 将普通盒子文件移到非桌面目录，再移回；移走后在桌面创建同名文件；关闭 MagiDesk 后改名再启动；刚移回时立即拖入另一个盒子或拖回桌面，确认手动选择不会被覆盖。

接口参考：[FILE_ID_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_info)、[文件 ID 复用限制](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/ns-fileapi-by_handle_file_information)。
## 2026-09-19：主屏自由布局与位置记忆

- 入口沿用原生桌面空白右键的“查看”：取消自动排列后可自由拖动；对齐网格开启时按格子摆放，关闭后支持像素位置及重叠。自动排列仍沿用从上到下、再从左到右的排序网格，开启自动排列不会清除已保存的自由布局。
- 单个和多选拖动采用桌面内的专用标记；多选保持相对位置，网格遇到占用时整组寻找附近空间，无空间则保留原位置。此电脑/回收站等虚拟图标只在自绘桌面内移动，不伪装成文件向外拖放。
- 位置按文件身份（无法读取时回退为路径）保存，Shell 图标按解析名称保存；位置单位为相对主屏内容原点的物理像素。常规改名继续沿用文件身份位置。尚未取得身份的新文件拖放位置，在下一次快照中迁移到身份键。
- 首次成功读取 Explorer 视图时按 PIDL 获取原生图标坐标并导入主屏内的项目，已有保存的位置不覆盖；不会修改原生图标坐标。样式、间距不同可能导致布局微调，其他显示器上的项目不按其坐标导入。
- 新项目寻找空位；超出一屏时仍可滚动访问。界面虚拟化、框选、键盘方向和重命名滚动定位共用实际图标坐标。工作区/分辨率变更会重新调整主屏窗口，临时边界限制不覆盖原保存位置。
- 首版支持排序字段/方向变化时重排自由布局；重复选择同一排序字段的重排仍待补齐。类型排序仍是扩展名语义，多屏分配仍是后续任务。
- 自动测试：新增 `DesktopLayoutTests` 21 项，含配置序列化、DPI 坐标转换、整组选中移动/避让、边界限制、网格碰撞、空间方向选择、框选、一万项布局及非索引顺序的虚拟化。Debug 临时目录构建通过，完整 107 项连续三轮通过；未启动应用、修改原生图标位置或进行截图。

实机验收：取消自动排列后拖动并重启；切换对齐网格；多选拖到已有图标附近；框选移位后的图标并使用方向键；移动回收站；从盒子拖回桌面；改变缩放/工作区后检查图标仍可访问。首次原生位置导入、Shell 菜单和真实 OLE 拖放仍待用户运行确认。

接口参考：[IFolderView::GetItemPosition](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifolderview-getitemposition)、[Microsoft 桌面图标位置示例](https://devblogs.microsoft.com/oldnewthing/20130318-00/?p=4933)。
## 2026-09-19：多显示器桌面

- 每个显示器创建一个透明桌面层，项目只分配到一个显示器。位置记录新增 `MonitorId` 和 `HasPosition`；旧单屏记录绑定升级时的主屏，新项目默认主屏，原生位置导入可以按所在屏幕分配。已有手动保存的位置不被原生导入覆盖。
- 使用 Windows 的显示器设备接口名称，无法取得时回退到 GDI 名称。更换接口、驱动重装或远程会话可能改变标识；找不到首选屏幕时安全回退到当前主屏，不承诺跨硬件标识变化自动对应。
- 断开屏幕时，相关图标在主屏空位临时显示，不保存临时坐标覆盖原屏幕记录；重新连接同一身份屏幕后恢复原归属。在临时显示期间主动拖动，则保存新的屏幕归属。
- 桌面内拖放在多个桌面窗口之间共享一次性的内部标记，按物理像素换算抓取点和组选中偏移。允许自动排列状态下跨屏迁移（目标屏按自己的排列方式显示）；同屏自由移动仍需关闭自动排列。
- 桌面菜单设置在各屏同步。刷新走统一分配，避免单屏刷新显示全部图标；在副屏通过原生菜单新建的文件会保留在该屏，并沿用立即重命名流程。跨屏拖动后目标屏保留选中状态。
- 监听显示器和工作区变化，250ms 合并事件后更新桌面窗口。统一桌面启用时，启动或拓扑变化会把标题不可见的普通盒子移回可见工作区；这类盒子的几何回退不会保存一套断屏前后独立的布局快照。
- 屏幕归属和坐标随配置保存；读取到文件身份后，较新的按路径记录优先迁移，防止刚拖到副屏的新文件回到旧位置。

新增 `DesktopMonitorTests` 24 项：三屏唯一分配、旧配置迁移、主屏切换、断连重连、缺失屏幕不覆盖坐标、占位记录、双向混合 DPI 拖动、负坐标及上方屏幕、普通盒子可见性、配置重载、原生显示器身份读取，以及延迟文件身份迁移。Debug 临时目录构建成功，完整 131 项无窗口测试连续三轮通过。原生测试只读取显示器信息，没有拔插屏幕、改变缩放、启动 MagiDesk 或截图。

待实机验收：100%/150% 双屏间来回拖动单个与多个图标；副屏新建并重命名；切换主屏；断开副屏确认临时显示且退出重启保留记录；重新连接副屏确认回归；断开期间主动移动图标后重连，确认新选择优先；检查普通盒子、其他应用与各屏桌面的层级。

接口参考：[EnumDisplayDevicesW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumdisplaydevicesw)。
## 2026-09-19：拖入回收站

回收站按 namespace 身份识别，优先于桌面位置移动和盒子归属处理。无修饰键拖入文件/文件夹后调用系统可撤销删除，保留原生确认和错误界面；取消、失败或部分完成后重新枚举实际内容，不预先删除归属记录。混合系统图标、无效路径、整盘、通配符及缺失文件的批次整体拒绝。Ctrl/Shift/Alt 手势暂不支持，不转为复制、链接或永久删除。

新增 17 项自动测试，通过注入原生操作验证删除参数、双零结尾、取消和错误，不实际删除用户文件或操作回收站。临时目录 Debug 构建通过，完整 148 项测试连续三轮通过。实机待验证：从桌面/盒子/Explorer 拖入单个和多个文件、取消确认、系统拒绝删除、回收站图标更新及还原文件后的归属。

## 2026-09-19：统一桌面类型名称排序

文件枚举时合并获取 Shell 显示名称和本地化类型名称，不为排序增加逐项 Shell 查询。统一桌面使用类型名称排序，同类型按显示名称打破平局，支持降序；系统图标仍按既定优先级置前。类型读取失败回退扩展名，文件夹不把名称中的点当成扩展名。普通盒子原有排序行为保持不变。

新增 8 项测试，覆盖类型/扩展名顺序相反、不同扩展名同类型、降序、系统图标优先、回退、原排序兼容及真实后台 Shell 枚举。临时目录 Debug 编译通过，完整 156 项无窗口测试连续三轮通过。尚未验收真实菜单效果；重复选择相同排序项后的重新排列仍待实现，不宣称所有排序细节与 Explorer 完全相同。

## 2026-09-19：重复选择排序项重排

从实际原生菜单层级识别排序子项，不依赖固定命令编号。简体中文/英文菜单的排序命令成功返回后，对各桌面层单独触发一次重新排列；该事件不保存到设置快照，后续设置重读、普通刷新及查看菜单不重复触发。自动排列模式不遗留自由排列的重置标志。复用现有位置保存规则，断连屏幕的首选坐标不被覆盖。未知语言不猜测排序意图，保留原有排序字段变化时重排的逻辑；日志记录命令识别及调用结果。

## 2026-09-19：系统图标自动更新与映射根目录恢复

## 2026-09-19：盒子单行标签分页

普通盒子的菜单提供“添加分页 → 手动整理 / 映射文件夹”。多个分页与标题同排，只显示选中/悬停下划线；单页显示普通标题。右键标签管理名称和关闭，最后一页不能关闭；整个盒子删除会移除该组全部分页，均不删除磁盘文件。统一桌面及内置桌面记录保持独立，避免桌面被隐藏进分页。

内容记录继续独立保存，通过 TabGroupId 组成一组；SelectedPageId 保存选中页。每组只建立一个窗口，切换复用窗口并保存分页的内容画布、选择、滚动与导航历史。最多保留 8 个分页视图缓存，其余分页保留导航；重启返回各页映射根目录。普通桌面文件枚举快照与归属覆盖所有分页，后台目录恢复也包含未选中的页。外观设置下拉框按分页列出，支持分别设置及全部统一调整。几何尺寸和折叠状态属于整组，内容、排序、外观及目录身份属于各页。

切换使旧枚举代际失效，撤销旧监听，先显示可用缓存再后台更新。原生新建回调保存发起页 ID，避免切换后错分归属。标签区域不接受文件拖入，Ctrl+Tab / Ctrl+Shift+Tab 切换页，拖标签超过阈值移动盒子。现有旧格式 Tabs 仍按之前的兼容规则恢复为独立盒子，新分组字段不会被该转换拆散；不自动将现有盒子合并。
