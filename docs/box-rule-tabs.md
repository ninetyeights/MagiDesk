# 盒子规则分类分页

在只有一个分页的普通盒子菜单中，选择“按规则分类为分页…”。已有多个分页时入口禁用；内置桌面不参与。

窗口预置图片、文档、压缩包三条规则，可以修改、增删及上移/下移。扩展名用逗号分隔，空表示不限；文件名支持 `*`、`?`；未修改天数填 `0` 表示不限。同一条规则的条件全部满足才匹配，按规则顺序首次命中生效。点击“生成分类分页”创建分类。

分类不会复制、移动或重命名任何文件。映射盒子分类映射根目录的第一层文件，手动盒子分类已有成员。文件夹和未匹配的文件显示在“其他”；进入子文件夹后正常显示其全部内容，不再应用根目录分类条件。

文件增删改名后复用盒子的监听刷新机制重新匹配；切换分页也会核对最新内容。时间条件在刷新时重新计算。配置重启后保留。向盒子添加文件后，显示位置由匹配规则决定，不保证停留在拖入的分类页。

关闭分类页只删除该分类，其文件重新匹配剩余规则，未匹配的回到“其他”。“其他”页保留，不允许关闭，避免失去文件入口。分类组首版不混用手动分页或其他文件夹映射；生成多页后不能重复执行分类。关闭全部规则页、只剩“其他”时可重新分类。

独立“文件整理”页面仍保留，其规则涉及复制/移动，与这里的虚拟分类互不关联。

自动回归涵盖单页限制、规则校验、首次匹配、兜底、条件组合、改名、分类关闭、手动成员共享、配置恢复和完整分区。实际窗口交互和外部监听刷新仍待运行验收。
